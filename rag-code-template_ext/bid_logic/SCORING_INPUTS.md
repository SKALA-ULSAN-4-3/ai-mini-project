# 정량 측정과 수동 판단의 요구조건

첨부된 `제안요청서(과업내용 포함).hwp`(합덕제철고 AI 활용 특허 교육 연수)를 대표 사례로 검증한다.
공고별 산정표를 추출해서 적용하며 이 학교의 배점·조건을 다른 공고에 하드코딩하지 않는다.
프론트엔드 변경과 정답 데이터 수정은 포함하지 않는다.

## 반환 방식

- 원문 구간표·등급표와 입력이 갖춰진 정량 항목은 `status=calculated`, 숫자 `expected`를 반환한다.
- 정량 입력 부족은 `missing_profile`, `missing_fields`, `questions`로 필요한 정보를 알린다.
- 정성 항목은 임의의 A~E 등급을 예측하지 않는다. `requirements`에 원문 인용과 출처를 보존하며,
  기존 화면의 근거 열에서 읽을 수 있게 `reason`에도 준비·확인 요소를 넣는다.
- 전문인력의 `4명 미만 / 1점` 같은 명시적 표는 코드가 직접 읽는다. 구간이 빠지거나 상충하면 계산하지 않는다.
- 에이전트가 계산 가능한 정량 항목에 `mark_manual`을 호출해도 고정 계산기를 실행한다.

## 입력 보완 API

기존 인증된 `GET /bids/{bid_no}/score?revision=000`은 유지한다.
인력·증빙 등 기존 Java 프로필에 없는 정보는 동일 경로의 **POST**로 요청 단위 보완할 수 있다.
Bearer JWT와 기존 프로필 조회가 필요하며, 추가 정보는 DB에 저장하지 않는다.

```json
{
  "notice_date": "2026-10-26",
  "personnel": [
    {"employed_from": "2024-01-01", "training_experience": true, "insurance_verified": true}
  ],
  "track_records": [
    {
      "completed_at": "2025-05-01", "amount": 21000000, "amount_unit": "KRW",
      "client_type": "public", "related_training": true,
      "vat_included": true, "evidence_submitted": true
    }
  ],
  "credit_rating": "BB0",
  "credit_rating_issued_at": "2026-01-01",
  "credit_rating_valid_until": "2027-01-01",
  "owned_docs": ["신용평가등급 확인서"]
}
```

위 날짜와 회사 정보는 설명용 가상값이다. 실제 공고일을 오늘로 대신하지 않는다.
서버가 해당 공고·차수의 CSV에서 찾은 게시일이 있으면 요청의 `notice_date`보다 우선한다.
`employed_to`가 없으면 현재 재직 중인 것으로 입력한 것이다. 인력은 이름·주민번호 없이
증빙 확인 결과만 전달한다. 동일한 사람을 중복 입력하면 안 된다.
`client_type`은 `national`(국가기관), `local`(지자체), `public`(공공기관), `private`(민간)이다.
사업 관련성 및 증빙 확인 flag는 사용자가 확인한 값이며 AI의 자격 인증을 의미하지 않는다.
실적 `amount`는 원문의 인정 조건에 맞는 자사 귀속 금액을 입력한다.

`null`/누락은 미확인, 빈 배열은 해당 실적·인력이 없다고 확인한 상태다.
증빙이 없다는 사실이 확인되었고 원문에 미제출 점수가 명시되어 있을 때만 그 점수를 적용한다.
기존 GET만 쓰는 화면에서는 추가 인력 정보를 입력하지 않았다면 계속 정보 부족 안내가 나타날 수 있다.

## 대표 문서 검산

- 실적: 건별 2천만원 이상, 인정 기간·기관·분야·증빙 조건으로 필터링한 후 기준금액 3천만원 대비 합산 비율.
  실제 사업예산 3천2백만원으로 나누지 않는다.
- 전문인력: 4명 미만 1점, 4~6명 3점, 7~9명 4점, 10명 이상 5점.
- 신용등급: 유효한 확인서의 기업신용등급으로 5/4/3/1점을 적용. 원문에 있는 미제출 0점도 지원한다.
- 정성 근거 예: 사업 관리 부문은 인력운용·조직 구성, 보고 체계, 연수환경 지원,
  돌발상황·안전대책, 정보 누출 방지·보안대책을 표시한다.

실제 HWP 텍스트로 AI 추출을 한 번 실행해 요구조건 전달을 확인했다. 이후 추가 모델 호출은
승인 거절로 수행하지 않았으며, 그 실제 응답을 원문과 함께 재생해 수정된 계산 경로에서
가상 입력의 실적 8점 / 인력 3점 / 신용 4점과 정성 4항목의 요구조건 표시를 확인했다.
이는 PDF 변환·웹 화면까지 포함한 전체 서비스 E2E 검증 결과는 아니다.

검증: `python -m unittest tests.test_representative_scoring tests.test_scoring_extraction`
배포 후 RAG 서버를 재시작하면 변경된 scoring 캐시 버전으로 다시 추출한다.
