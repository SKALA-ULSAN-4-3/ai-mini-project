# 모델 선택 근거 (2026-10-26 측정)

교재 실습 코드의 기본값(gpt-4o)을 그대로 쓰지 않고, 같은 평가셋으로 대안 모델과 비교해 골랐다.
한 번에 모델 하나만 바꾸고 검색 · 프롬프트 · 평가셋은 그대로 두었다.

## 1. 질문 답변 (`/rag-query`): gpt-4o 유지

평가셋 56문항 = 테스트 공고 2026-01 26문항 + 실제 나라장터 공고 3건 30문항 (문서에 없는 예외 질문 7개 포함).

| 항목 | gpt-4o | gpt-4.1-mini |
|---|---|---|
| 정답 (답 있는 질문) | **49/49** | 48/49 |
| 근거성 (기대 쪽 인용) | **49/49** | 48/49 |
| 예외 처리 (handoff) | **7/7** | 6/7 |
| 환각 (예외에 답 생성) | **0/7** | 1/7 |
| 평균 응답 시간 | 약 1.9초 | 약 1.8초 |
| 토큰 (56문항 합계, 실측) | 입력 336,368 · 출력 2,828 | 입력 336,368 · 출력 3,452 |
| 비용 추정 (56문항) | 약 $0.87 (문항당 약 $0.016) | 약 $0.14 (문항당 약 $0.0025) |

비용은 공개 단가(100만 토큰당 gpt-4o 입력 $2.50 · 출력 $10, gpt-4.1-mini 입력 $0.40 · 출력 $1.60) 기준 추정이다.

gpt-4.1-mini가 틀린 문항:

- **E01 "이 사업의 예상 낙찰가는 얼마야?" (문서에 없음)**: "예상 낙찰가는 81,400,000원"이라고 답함.
  사업금액(투찰 상한)을 낙찰가로 바꿔 말한 환각. gpt-4o는 "문서에 명시되어 있지 않습니다"로 넘김.
- **Q13 "배점이 가장 큰 평가부문은?"**: 정답 '기술 및 기능'(35점) 대신 25점 항목을 답함.
- C03 "납품기한은?": 답은 맞고 기대와 다른 쪽(p.18)을 인용.

**결정**: 응답 시간 차이는 0.1초로 작고, 입찰 업무에서 가장 위험한 오류(문서에 없는 금액을 만들어 냄)가
작은 모델에서 나왔다. 문항당 약 1.5센트 차이보다 이 위험이 크므로 gpt-4o를 유지한다.
요약 · 채점표 · 제출서류 추출도 금액 · 날짜 · 배점을 다루므로 gpt-4o를 유지한다 (결과는 공고별로 캐시).

결과 파일: `results/*_model_gpt-4o_*.csv`, `results/*_model_gpt-4.1-mini_*.csv`

## 2. 음성 (X3)

입찰 질문 8문장을 비교 대상이 아닌 목소리(tts-1-hd, onyx)로 음성으로 만든 뒤 받아쓰기.

| 받아쓰기 | 글자 오류율 | 완전 일치 | 평균 시간 |
|---|---|---|---|
| whisper-1 | 9.7% | 5/8 | 1.25초 |
| **gpt-4o-mini-transcribe** | **6.5%** | **6/8** | **0.91초** |

- whisper-1은 "제안서"를 "제한서"로 받아씀 (입찰 핵심 용어). gpt-4o-mini-transcribe는 정확.
- 업종코드 "1468"은 둘 다 틀림. 숫자 읽기("일억 오천사백오십사만" → "1억 5,454만")는 둘 다 올바르게 바꿨으나
  글자 오류율에는 오류로 잡혀 실제보다 높게 나온 값이다.

| 읽어 주기 | 시간 | 다시 받아쓴 오류율 |
|---|---|---|
| **tts-1** | **1.36초** | 0% |
| gpt-4o-mini-tts | 2.39초 | 0% |

**결정**: 받아쓰기는 gpt-4o-mini-transcribe로 바꾸고, 읽어 주기는 정확도가 같고 1초 빠른 tts-1을 유지한다.
목소리 품질(자연스러움)은 사람이 들어 보고 판단할 부분으로 남긴다.

## 3. 임베딩: text-embedding-3-small 유지

바꾸면 저장된 공고 문서를 모두 다시 적재해야 하고, 현재 평가에서 검색 누락이 없다(근거성 49/49).

## 바꾸는 방법

루트 `.env`에 넣으면 코드 수정 없이 바뀐다: `RAG_LLM_MODEL`, `EXTRACT_LLM_MODEL`, `STT_MODEL`, `TTS_MODEL`, `TTS_VOICE`.
gpt-5 계열(추론형)은 `temperature`를 받지 않아 그대로 넣으면 오류가 날 수 있어 비교에서 뺐다.
