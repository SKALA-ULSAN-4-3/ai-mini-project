## 판정 기준

관심 분야 또는 기존 실적의 업무 범위와 핵심 과업이 직접 연결됨. 둘 중 하나면 관련 있음.

세 프로필 공통 대학 학사정보 실적은 학사·학생지원·학습관리 업무에 전이 가능하다고 판정. 신규 공고에 Axis 명시가 필수는 아님.

시스템/개발 같은 일반 단어, 동일 발주기관·대학이라는 이유만으로 관련 판정하지 않음. 직접 연결 근거가 부족하면 평가 정답에 포함하지 않음.

마감·금액·지역 제외 사유는 주제 관련성과 별도로 기록했다. 미확인 업종·면허는 임의로 탈락시키지 않았다.
추천 결과는 기존 작업에서 확인했으므로 블라인드 평가는 아니다. 순위·유사도 수치에서 정답을 생성하지 않고 원문 사업 범위와 프로필을 대조했다.
